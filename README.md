# rack2r-linux
Rack2R mod v12 working on linux
DISCLAIMER: I DO NOT own any of these assets/files, ive just patched dll and renamed fbx + added netstandard. 

# how to use
move **netstandard.dll** and **Assembly-CSharp.dll** to **game_folder/Rack 2_Data/Managed/**
move **fbx** file to **game_folder/Rack 2_Data/Managed/RackRAssets** 
**start** the game, create a character if you didnt, make game load assets (eyes in menu may be not loaded first) and **restart** game
