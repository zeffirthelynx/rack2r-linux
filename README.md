# how to install mod
1. move **netstandard.dll** and **Assembly-CSharp.dll** to **game_folder/Rack 2_Data/Managed/**
2. move **fbx** file to **game_folder/Rack 2_Data/Managed/RackRAssets** 
3. **start** the game, create a character if you didnt, make game load assets (eyes in menu may be not loaded first) and **restart** game
